# Sample Inputs

This folder contains the numbers or text supplied to a running program.

**[Open the C programs](../C_Programs)** · **[See sample outputs](../LAB_RECORD.md)**

Input files for **001, 002, 015, 022, 024, and 091** are intentionally empty:
those programs run without reading input. An empty input file is expected.

For example, `009.txt` contains `C 100`, the input for Celsius-to-Fahrenheit
conversion. The matching source is in `C_Programs`; its output is in the lab record.
